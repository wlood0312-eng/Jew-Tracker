MONEYTRACK — Android loyiha (1.0)

NIMALAR ISHLAYDI
- Daromad va xarajat qo'shish
- Balansni avtomatik hisoblash
- Kategoriya va izoh kiritish
- Operatsiyalar tarixini ko'rish
- Jami daromad/xarajat statistikasi
- Ma'lumotlar telefonda saqlanadi (offline, localStorage)

APK YIG'ISH
1. Android Studio o'rnating (Android SDK bilan).
2. Ushbu MoneyTrack papkasini Android Studio orqali Open qiling.
3. Gradle sync tugashini kuting.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) ni tanlang.
5. APK odatda app/build/outputs/apk/debug/app-debug.apk ichida bo'ladi.

TALABLAR
- Android Studio va Android SDK Platform 33
- JDK 11 yoki 17
- Android 6.0 (API 23) va undan yuqori

ESLATMA
Bu loyiha manba kodi. Ushbu muhitda Android SDK/build-tools mavjud bo'lmagani
uchun tayyor APK kompilyatsiya qilinmadi. Android Studio orqali yuqoridagi
qadamlar bilan APK olinadi.
